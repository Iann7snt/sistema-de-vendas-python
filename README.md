# Sistema de Vendas em Python

## Sobre o projeto
Projeto acadêmico desenvolvido em Python para aplicar conceitos de lógica de programação por meio de um sistema de vendas executado no terminal.

## Arquivos do projeto
- `sgv.py`: código-fonte do sistema.
- `Relatorio_SGVpy.pdf`: relatório acadêmico.
- `Fluxograma_Sistema_Vendas (1).pdf`: fluxograma do sistema.

## Como executar
Abra o arquivo `sgv.py` em um ambiente com Python instalado e execute o programa.
